# Image prompts

The landing page and README look for these files under `web/brand/`. Each one is optional. If the file is missing, that slot stays hidden.

The ChatGPT prompt text was not in the repository, so this file only names the slots.

| File | Where it shows up |
| --- | --- |
| `og.png` | Open Graph and Twitter card image |
| `icon.png` | Favicon |
| `keyart.png` | Loading screens gallery, first frame |
| `load-1.png` | Loading screens gallery, and the city loading overlay |
| `load-2.png` | Loading screens gallery, and the city loading overlay |
| `load-3.png` | Loading screens gallery, and the city loading overlay |
| `banner.png` | README wordmark, when the file is present |
